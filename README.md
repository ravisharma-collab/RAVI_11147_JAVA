# Smart Warehouse Grid Locator

## Project Overview

The Smart Warehouse Grid Locator is a Java-based Object-Oriented Programming project that uses a 2D array to represent a warehouse grid.

Each grid position stores a GridItem object containing:

- Item ID
- Item Name
- Quantity

The system allows users to:

- Display warehouse grid
- Search items by ID
- Update item quantity
- Remove items
- View exact row and column locations

## Technologies Used

- Java
- Object-Oriented Programming
- 2D Arrays
- Nested Loops

## Learning Outcomes

- Understanding OOP concepts
- Working with 2D Arrays
- Searching algorithms
- Object storage and retrieval
